# 🏥 Patient Management System

A simple and responsive **Patient Management System** developed using HTML, CSS, and JavaScript. This project helps manage patient records efficiently by implementing CRUD (Create, Read, Update, Delete) operations.

## 📌 Project Overview

The Patient Management System is a frontend web application designed to maintain and manage patient information in an organized manner. It provides an easy-to-use dashboard with a modern maroon and white theme.

## ✨ Features

- **Add Patient:** Register new patients with their personal and medical details.
- **View Patients:** Display all registered patients in a structured table.
- **Update Patient:** Edit and update existing patient information.
- **Delete Patient:** Remove patient records with confirmation.
- **Search Patients:** Search patients by name, ID, disease, or doctor.
- **Dashboard Statistics:** Display total, male, and female patient counts.
- **Local Storage:** Save patient records in the browser.
- **Responsive Design:** Supports desktop and mobile screens.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser.
5. Start adding and managing patient records.

## ⚙️ CRUD Operations

| Operation | Description |
|---|---|
| Create | Add new patient information |
| Read | View registered patient details |
